# Modelos visuales de Jarvis

Estos son los modelos de escena de Blender usados para la representación visual de Jarvis/Living Core. No son modelos de IA.

| Archivo | Uso |
| --- | --- |
| [`models/jarvis/living-core-validation-test.blend`](models/jarvis/living-core-validation-test.blend) | Escena usada para el render que aparece en la web app. |
| [`models/jarvis/living-core-validation.blend`](models/jarvis/living-core-validation.blend) | Escena de validación y respaldo. |
| [`models/jarvis/living_core_blender.py`](models/jarvis/living_core_blender.py) | Generador reproducible de la escena animada. |

La web app conserva sus renders y máscaras visuales en `apps/web/assets/`.
